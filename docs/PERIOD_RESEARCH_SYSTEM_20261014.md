# 按周期的研究体系（2026-10-14）

## 边界

本轮完善中线（1–3个月）和长线（6–12个月）的流程、角色职责、数据需求和呈现；不把短线报告改标题后当成长线报告。研究流程可验证不等于投资预测准确，不能承诺收益、回测胜率或完整免费数据覆盖。

本轮仅开发与隔离验收：不部署 Mac 生产、不改历史报告、不触发模型调用/付费分析、不全市场补数、不改变 Jev 或自动补数开关。生产基线仍为 `0dac0e57`。

## 运行机制

- 原 `default-4stage` 工作流条目和 `agents.json` 保持原文；短线角色提示词、数据窗口、阶段开关、记忆命名和默认行为不变。
- 新增 `research-medium` / `research-long` 工作流种子。启动时沿用现有 seeder：DB `workflow_specs` 运行时权威；自定义条目不覆盖、已删除条目不复活。没有写入生产 DB。
- 周期角色完整正文、显示名、数据工具和输入契约放在该工作流的 `research_profile`，不是追加到短线角色正文。每种周期覆盖6个分析师、两名研究辩手、研究裁决、计划师、三名风险辩手、最终风控及摘要共15个角色。
- 运行时冻结工作流副本，使用任务局部 ContextVar 选择提示词；并发的短/中/长任务不共享周期角色。原 `agent_specs` 不改写。自定义工作流必须显式配置相同周期的 profile，禁止静默替换用户自定义流程或回退短线角色。
- 页面校验、任务接收和引擎编译共用周期准备函数；选择原默认流程但传中/长周期的旧客户端自动路由到对应周期流程。新页面只列兼容流程，保留切回短线时原选择；必需角色可见且不可取消。

## 周期差异

| 项目 | 中线 | 长线 |
|---|---|---|
| 核心问题 | 业绩和事件能否在一至两个报告期兑现 | 商业质量、现金创造和资本配置是否支持持有 |
| 基本面 | 盈利质量、现金回款、库存应收、催化兑现 | 商业模式、竞争优势证据、治理、资本回报、价值陷阱 |
| 研究辩论 | 一轮正反论证及裁决 | 两轮价值创造/永久损失论证及裁决 |
| 计划 | 条件建仓、持有、业绩/估值证伪 | 分批与持有逻辑、资本损失与估值再评估 |
| 风险 | 一轮上行/下行/一致性审查及最终裁决 | 一轮增长机会/永久损失/估值稳健性审查及最终裁决 |
| 复查 | 月度、财报或重大事件 | 季度、年报或重大事件 |

两种流程都强制基本面与财经新闻角色，以及研究辩论、计划、风险裁决、摘要；其余角色按用户选择。复用原编排机制和报告键，保留原提交协议、账户语义和风控。两种新流程仅选必需角色时分别11/13个执行单元（不等于实际模型请求数，工具循环可能多次请求）。相比关闭辩论的短线流程会增加耗时/用量，页面显示实际计划，不自动运行。

## 数据与缺项

- 基本面优先基础信息、报价、财务历史、基本面综合、估值指标与公告；沿用之前已验证的周期财务、估值和技术窗口。
- 技术角色用日/周/月趋势；不再预注入分钟线。中线资金仅辅助；长线资金角色不强制五日流、两融或龙虎榜。
- 新闻/情绪共享冻结样本：短线仍30天/最多读取100条/默认15条；中线90天/200条/默认30条；长线365天/400条/默认60条。查询有边界、降级不循环补抓，列采样上限、截断及真实发布日期，不保证窗口内全量新闻。
- 公告链路仍主要为A股定向正文摘录（现有420天检索、6份财报及最近90天公告选取限制）；港美股、历史年报、行业份额、管理层资本配置细节、可靠预测参数仍可能不足。扩大研究窗口不等于新增数据源或已经取齐。
- 缺项只限制依赖它的结论；关键估值输入不足时保留有据定性研究，不编造DCF参数、目标价或胜率。单项新闻/分时/资金缺失不能自动变成全部风险未知或0%总仓。
- 事实、计算、假设、反证分开；财务报告期与披露日分开，不使用截止日以后信息。公允价值、技术位置和条件目标分开，未知仓位和置信度不补默认数。

## 冻结与重试

执行快照记录周期、工作流哈希、profile版本/哈希与角色名称；中长线执行前另落一条快照事件，失败任务也可核对来源。中长线复用旧报告须工作流哈希一致且有新 profile 快照；旧“周期追加说明”报告或提示词已变的报告拒绝混用，提示重新发起完整分析。短线既有重试行为不变。用户未发起分析前不会因升级自动重跑。
