# 日线缠论图层与威科夫失败展示

第一版沿用短线持续研究的 DataInterface → 不复权日线 → ECharts 链路。缠论不调用模型，不改变分析师、综合复核、仓位、预算或自动更新开关。

## 计算边界

- CZSC 1.0.2 原生核心计算分型、笔、笔中枢。没有接入线段、一二三类买卖点、背驰或交易执行；不作盈利能力声明。
- 当前图表通常提供最多 140 根日线，适配器硬上限 400 根，最小连续窗口 20 根。仅接收明确 raw/CNY、同源、有限且合法的 OHLC 和完整交易日历。
- 日期缺口只允许使用最后缺口之后的连续窗口；最新日线未到齐时保留实际截止日期。不同来源的完整日线、复权口径、重复日期和无效价格不拼接。
- 逐日回放记录 `confirmed_at`（当前连续存在的结构首次获算法确认）和 `updated_at_session`（当前几何/确认状态形成的日期）。中枢扩展可保留最初三笔确认日期，但延伸部分有自己的更新时间。转折日不是确认日。
- “确认”仅指该日算法状态；后续走势、供应商修订、除权除息、滚动窗口变化仍会修订结构。收盘快照按输入哈希保存，修订另建快照，不覆盖旧记录。
- 日线只用 OHLC；原生接口中的量额设为 0，不计算量能背驰或力度。已有图表成交量仍使用实际成交量。
- 盘中数据只使用现有已校验报价，独立计算候选层、标明快照来源与时间；不改写闭合日线结构，不存为收盘确认记录。报价过期/乱序时不保留候选叠层。
- 新研究版本保存当时的缠论结果；旧版本没有结果时明示“尚未保存”，不以后来行情回填。展示分型、笔、笔中枢、候选、报告点位、威科夫可分别开关。

## 依赖与兼容

上游：[waditu/czsc v1.0.2](https://github.com/waditu/czsc/tree/v1.0.2)，声明 Apache-2.0。原生扩展通过 `importlib` 加载已安装发行包自身的文件，不执行顶层包对完整回测/绘图依赖的导入；不注入伪 Python 包。适配器依赖私有原生接口，版本必须固定，升级时必须重跑逐日回放并修改 `ENGINE` 缓存版本。

Docker 构建安装 `czsc==1.0.2 --no-deps --only-binary=:all:`。Miniconda 测试环境同样使用无依赖安装，pandas 已是系统依赖；`[chan]` extra 仅声明固定版本，直接使用普通 extra 安装会引入 CZSC 完整传递依赖。验收用 `--target` 安装到临时目录，没有更改生产或共享 conda 环境。

已验证 macOS arm64 / Python 3.12 和生产基础镜像 Linux aarch64；其他平台未验收。官方 PyPI wheel SHA256：

- macOS：`30a62a9245da2f875a5da7b7dfdffdb1206cdced5ff16d7d3a74633272ec841c`
- Linux aarch64：`3e34e4e582b0389e951d5fcbcab22d47887b3494b5be7ad16ebff484c0c63ec3`

## 威科夫失败时的展示

旧提示在 `current=None` 时仍称“保留上次判断”，且仅查询当前起点；切换起点后，较早研究的判断看不到。现在先区分当前起点有无有效阶段；无有效阶段时在同账号、同股票、所选版本时间之前查找较早起点的有效记录，单独显示原日期、原文和来源入口，不并入当前阶段或当前图层。没有合格记录就明确说明。

阶段校验失败继续保留其他技术研究，不额外重试模型。新记录保留字段路径和错误类型，排除输入值；旧记录若仅有错误总数则明示无法恢复字段详情。原文与证据、结构日期、阶段转换等校验没有放宽；本补丁不保证未来模型永远正确提交结构。

## 验收

Mac Miniconda + 独立真实 Mongo/Redis：263 项后端检查；22 项前端检查；vue-tsc/Vite 构建通过。三股 000503/002241/603232 的真实 raw 日线各 140 根，共 363 个逐日截断窗口，与原生批量计算一致；Linux aarch64 几何、状态和确认时间一致。单次核心计算约 0.06–0.08 秒，验收进程峰值约 114 MiB（不是服务增量内存承诺）。

生产记录只读导出到隔离库验证，三股均可找回较早起点记录。实际 Vue 页面验证同起点保留、跨起点来源跳转、无记录、未捕获缠论的历史版本、切股、图层开关，以及 390px 小屏。界面样例研究文案明确标注合成，行情来自实际日线。没有生成或重跑分析。

验收证据位于 `.ai_temp/archive/chan-wyckoff-20261104/`。当前补丁未部署；上线需新镜像包含原生依赖，并等待全部分析/每日研究任务空闲及 scheduler 扫描安全窗口，保留原镜像回滚。
