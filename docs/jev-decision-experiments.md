# Jev 日线动作试验 v1

## 自动动作建议（新主入口，默认关闭）

### 生成时分区（strategy-partition-v1）

交易计划与最终裁决在同一次模型生成中按 `strategy:public`、`strategy:account-unheld`、`strategy:account-held`、`strategy:end` 四个 HTML 注释标记分区。公共区保留完整公开研究、替代路径、前置/否决/退出条件、日期口径与出处；两个账户区只保存本地执行约束。无账户依赖的对应区留空，未知不能伪装成已满足。原提交正文和决策参数不由分区器改写，不新增模型调用，不修改数据库中的用户智能体配置。

提交时校验分区；保存时从规范报告原文重新派生 `strategy_partition`，包含原文哈希、公共策略和本地账户约束。读取准备材料时再次绑定，不能用陈旧或伪造的分区绕过完整性检查。标记外文本、重复/嵌套标记、代码围栏、缺失公共区均不作完整材料。分区失败只使自动 Jev 记录不可用，不令报告提交或原分析失败；不自动改写历史报告。

自动 Jev 只接收公共区和已有脱敏分析师摘录，账户区原文不外发。公开区误含敏感事实仍拦截；引用网址只在外发副本替换为“链接仅本地保留”，同行风险条款不得删掉，原报告链接不变，链接正文不视作已取得证据。结构分区完整不代表事实或语义完整。

账户约束未核验时仅屏蔽对应假设分支；发现共享/错放的账户条款会同时屏蔽相关分支。两个分支都受限时不调用；仅一个受限时，Jev 评价其余分支，受限分支的模型建议无论为何都被本地降为 `RESEARCH_REQUIRED`。原新增额度上限继续生效。公共证据自身不足或矛盾仍不能给确定动作。无法推断的依赖仍可能被保守拦截，不承诺所有未来报告都能产生 Jev 建议。

新增回归：`tests/data/test_strategy_partition.py` 覆盖真实提交工具、短/中/长期保存钩子、独立分支、共享约束、脱敏、全文覆盖、分区篡改、原报告不变和不调用模型。模型实际是否遵循新输出约定需要后续获准的新分析验证，离线通过不等于真实模型效果验收。

自动模式不需要人工选段。分析师、辩论及原最终裁决照常完成，报告成功保存后排队一次独立的 Jev 动作判断；主流程不等待模型。报告详情并列显示 Jev 原始建议和本地规则检查后的结果，不改变原裁决、价格或仓位，不下单。

- 独立配置 `final_action_enabled`，默认 false。首次启用须确认后续新报告可自动外发一次；总开关、外发开关、密钥和共享日预算仍有效。旧客户端省略新字段时保留其值。
- 自动模式开启时，同一份报告不再触发旧条件核验；旧记录保留。关闭自动模式时沿用旧行为。旧核验历史、手动日线调试折叠到辅助区域，不能把关闭总开关当作仅停止旧核验。
- 输入是完整最终方案的公共投影及六类分析师证据摘录，明确携带分析日期、周期及各摘录缺失/部分可用状态，不获取新的行情、不把研究日期断言说成当前事实。沿用普通每份5000、最终30000、合计48000字节范围，不发送实际持仓、成本、余额、用户ID、凭据和内网信息。
- 对完整公共方案做完整性检查，而不是只挑有价格的句子。旧规则修订表必须保留否决语境，不能当作当前授权。新报告按上述分区准备；历史无分区的报告保留原保守检查。若公共策略与私有事实混写导致关键条件丢失、公共区仍隐含未知账户规则或超限，记录 `skipped` 和具体原因，不外发、不编造确定动作。这是自动处置缺项，不是要求用户挑选另一段来绕过。
- 三个类型化字段：假设未持仓 `BUY / WAIT / RESEARCH_REQUIRED`；假设已持仓 `ADD / HOLD / REDUCE / SELL / RESEARCH_REQUIRED`；证据状态 `SUPPORTED / INSUFFICIENT / CONFLICT`。未知不默认持有。仅在已核实的明确正新增额度下允许买入/加仓展示；模型越过上限时保留原建议供审计，但拦截有效结果。
- 不发送实际账户状态，两个分支始终是假设。明确枚举不等于预测准确，没有真实调用或效果评估时不能宣称模型有效。
- 独立集合 `jev_final_actions`，每个报告/规则版本最多一次；4个待处理任务、25秒总期限、无重试。关闭配置或报告变化在发送前再次检查。保存中断显示未完成，不自动重发。原报告/任务/裁决不写回。
- `GET /api/jev-decisions/{analysis_id}/final-action` 仅所有者只读；打开页面或刷新不会创建记录、补跑旧报告或调用模型。旧报告没有自动记录属于预期行为。

测试入口：`tests/data/test_jev_final_action.py`、`frontend/tests/jevFinalAction.test.mjs`。验收必须覆盖真实保存钩子、短/中/长期、共享预算、只选一条自动路径、所有权、无副作用读取、真实报告隔离副本和实际页面。样例响应仅验证解析/展示，不冒充真实 Jev 成功调用。

## 定位

研究模型负责深度研究；Jev 使用已确认的公共策略和更新后的市场状态，快速选择有限动作。
这是独立的 paper/shadow 试验，不是整篇报告审稿、交易授权、自动交易或准确率承诺。
原报告、分析师、各周期提示词、辩论、最终裁决和历史核验记录都不改写。

首版手动触发、日线级，支持报告周期 short/medium/long，但六个交易日日线不等于完整中长线研究。
没有定时器、自动重试、盘中盯盘、全市场补数或券商接口。现有条件核验开关及记录保持独立。

## 使用路径

1. 报告详情 → **Jev 动作试验** → 展开准备材料。
2. 页面在本地从最终裁决（缺少时使用专业交易员计划）识别入场、退出和否决候选，显示来源及起止行号。
   唯一、未超限的明确条件章节自动填入；多个候选和未分章节的整段文字须人工选择，不默认第一项。
   保留完整章节及子标题、表格、附带段落，不总结、不生成价格或条件、不静默截断。识别不到不等于报告一定没有；请核对完整原文。
   空标题、仅缺失说明不能当作可用条件。超限或代码段不自动选用；可人工选取其他完整原文行，不允许补写或只截取半句。
   使用者仍须核对其他章节的限制、例外、跨段依赖及替代方案，并确认完整性和有效期；系统不声称自动证明语义完整。
   本地识别不请求行情、不调用模型、不修改报告。修改选段或切换报告会撤销确认并清空预览。
3. 确认策略有效期。不能早于今天，也不能晚于报告日期加14/93/366自然日的试验上限；这只是上限，不自动延长原策略有效期。
4. 点击“获取日线并本地预览”。经 DataInterface 读取交易日历，单股 read_ready 有界读取/补取六个已收盘交易日日线。
   最晚从北京时间15:10起使用当日日线。缺日历不猜工作日；缺数据、口径不明、来源冲突或超时明确显示，不调用模型。
5. 检查策略原文、行情日期、价格、来源和完整外发材料。材料中每项 `projection` 标明是否进行了公共策略称谓转换，`text` 是实际将发送的文字，`source_section` / `start_line` 对应原文出处。预览最长10分钟，日收盘边界和策略到期也会使其失效。
   编辑材料须重新确认与预览。
6. 管理员在 Jev 设置显式启用新的“允许手动动作试验”开关；它默认关闭。
   既有总开关、外发开关及密钥仍必须可用。启用开关本身不调用模型。
7. 点击调用并明确确认一次外发。相同报告版本、策略及行情材料只能尝试一次；刷新仅读取记录。

## 输入与输出

- 公共策略合计≤5000 UTF-8字节，策略＋行情合计≤8000字节，不做静默截断。
- 只发白名单字段：证券代码、研究周期/日期/有效期、已确认原文与出处行号、是否允许假设新增候选、六个已收盘交易日日线及口径限制。
- 不发送原报告全文、用户/任务ID、真实持仓/成本/账户金额、凭据、内网地址。先逐字绑定完整原文行，再生成受限公共投影，只发送投影、不发送未经检查的原文。
  公共“账户约束／账户硬约束／账户风险约束”改称“策略资金约束／策略资金硬约束／策略资金风险约束”；“不编造买入价、保护价或仓位额度”标为“策略禁止编造买入价、保护价或仓位额度”。保留全部前提、数字和否定限制，不自动删行、删句或概括。其余脱敏删改仍拒绝，错误标明入场／退出／否决项。仅统一 CRLF 换行，不改变原报告。
  原文和投影均受5000字节预算约束。规则版本更新后，旧预览必须重新生成和确认。既有报告条件核验使用的脱敏规则不变。
- 两个分支始终都是假设，不以实际账户事实选择分支。
- 输出三个类型化字段：`entry_action`、`existing_action`、`risk_state`。
  新增分支可等待、要求研究，或在硬规则允许时给“入场候选”；存量分支可给继续持有候选、退出复核或要求研究。
  条件风险状态为支持条件、否决/退出、证据不足。矛盾组合或模型版本变化不采纳。
- 当前新增额度为零、未知、非有限数值，或缺显式来源证明时，代码不提供入场候选选项。
  现有额度不是未来情景自动获批；后续需要新授权时，应更新研究，不由 Jev 自行越权。
- 规则基线明确为等待/需要研究，只检查完整性和硬规则，不伪装成另一模型结果。不展示分类置信度为胜率。

## 数据与可靠性边界

- 只接入日线状态，不重新核实财务、新闻、周线形态、盘中回踩或流动性。缺少必要当前证据须等待或重新研究。
- 全部价格为CNY/raw；无复权收益计算。公司行为造成的价格断点不能据此推断盈利或亏损。
- 选单一来源完整序列，不拼接多个供应商。可比raw价格来源差异超过0.2%时停止；这个阈值只是数据冲突筛查，不是交易阈值。
- Preview/run/history 独立于分析主路径；只写 `jev_decision_previews` / `jev_decision_experiments`。
  调用尝试共享 `jev_condition_budgets` 的北京时间日限额，预留次数不会因为失败退回。
- 发送前重读配置、报告版本与过期状态。固定 TypeSafe endpoint，禁重试/重定向/环境代理转发密钥，调用有超时。
  已发送而保存失败的记录显示未完成，不自动重发。关闭开关无法撤回已经发出的请求。
- 暂无自动从任意长报告提取完整策略的语义保证；不自动调用付费模型来生成压缩摘要。
- 无回测收益、准确率、胜率或延迟性能结论。需要后续授权的真实调用和跨状态对照评估。

## API

- `GET /api/jev-decisions/{analysis_id}`：所有者读取最近10条记录，不触发获取/补跑。
- `POST /api/jev-decisions/{analysis_id}/preview`：StrategyInput，建立本地预览。
- `POST /api/jev-decisions/{analysis_id}/{preview_id}/run`：要求 `confirm_external=true`，开关/所有权/版本/预算/时效检查后最多调用一次。
- 现有配置接口新增 `decision_experiments_enabled`。旧客户端省略它时保持原值；首次启用须明确确认外发范围。
